# Personal GitHub Pages Site

This repository contains a Jekyll-based personal website and blog for GitHub Pages.

## Included

- homepage with intro and contact links
- about page
- blog index page
- GitHub Pages configuration using Jekyll

## Files to customize

- `_config.yml` — site title, description, URL, and page settings
- `index.md` — homepage content
- `about.md` — about page

## Local preview

Use a modern Ruby version (3.3 or newer is recommended) and run:

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000

## Publishing

Push this repository to GitHub and enable GitHub Pages in the repository settings. For a user site, the repository should be named `yourusername.github.io`.
